# 智能中英输入法自动切换 (CAD Auto IME)

>
> **AutoCAD 智能中英输入法自动切换插件**
>
> "让绘图设计更加专注，减少手动切换输入法的繁琐打扰"
>

根据当前命令与编辑状态自动切换中英文输入法，减少手动切换的操作中断。

- **版本**: v0.4.3
- **命名空间**: `OpenCadIme`
- **核心能力**: 智能状态感知 | 双轨接口协同 | 跨版本适配 | 多文档独立隔离

---

## ✨ 功能特性

- **智能状态感知**：执行文字与标注类命令时自动切中文，执行常规绘图与快捷键时自动保持英文。
- **状态决策机制**：结合「命令事件监听」、「窗口焦点检测」与「行为时序辅助判断」，减少动态输入框与输入法候选框的冲突。
- **延迟安全初始化**：等待图纸与界面完全就绪后再启动监听，提升早期版本与高版本 CAD 启动时的稳定性。
- **跨版本依赖适配**：自动适配 WinForms 与 WPF 界面，利用资源 `AssemblyResolve` 依赖解析机制，保障 2007~2027 各版本 CAD 配置界面的正常唤起。
- **多文档状态独立**：每张图纸维护独立的输入法上下文，多窗口作业互不干扰。
- **可视化白名单配置**：支持自定义添加文本命令的图形化管理界面，支持撤销/重做与恢复默认。
- **隐式命令支持**：支持双击编辑文字（`_TEXTEDIT` 等隐式命令）自动切换。
- **命令免打扰**：区分系统后台响应与用户手动输入命令，手工呼出面板时不弹干扰窗。
- **常用命令内置**：内置常用的 CAD 原生文字命令与扩展命令，开箱即用。
- **轻量资源管理**：复用事件缓冲区，减少不必要的对象分配与性能影响。

## ⚙️ 白名单配置指南

### 配置面板操作

在 CAD 命令行输入 `CUSTOMAUTOIME` 打开配置面板，支持以下操作：

- **添加命令**：输入命令全称，回车或点击添加。
- **批量添加**：支持空格、逗号、分号分隔的批量输入。
- **删除命令**：双击条目或选中后按 Delete 键。
- **搜索过滤**：顶部搜索框实时过滤。
- **撤销/重做**：Ctrl+Z 撤销，Ctrl+Y 重做。
- **恢复默认**：一键恢复系统内置的默认命令。

>
> ⚠️ **重要提示**
>
> 添加命令时必须输入**命令全称**（Full Command
> Name），不能使用自定义的快捷键（Alias）。
>
>
> - ✅ 正确：`BLOCK`, `CIRCLE`
> - ❌ 错误：`B`, `C`
>

### 配置文件位置

```
C:\Users\用户名\AppData\Roaming\OpenCadIme\AutoImeCommands.txt              
```

配置文件为纯文本格式，每行一个命令，支持`//`开头的注释行。进阶用户也可直接编辑该文件，重启 CAD 后立即生效。

## 🧩 工作原理

### 四维立体判定与调度机制

插件采用多维协同机制，精准判断当前输入环境并无损调度输入法：

1. **命令事件引擎**：监听 CommandWillStart 和 CommandEnded 事件，当执行白名单内的文字命令时，标记“文本命令激活”状态。
2. **焦点雷达与最高裁决权引擎**：通过 SetWinEventHook 与 Win32 拓扑分析实时捕获真实焦点，赋予文本控件“焦点最高裁决权”，彻底杜绝画布逻辑误压制天正、探索者、CASS 等第三方 C++/MFC 弹窗输入框。
3. **行为时序引擎**：深入 Windows 消息流拦截 WM_LBUTTONDBLCLK (双击)，通过精确到毫秒的 1.5 秒时序容差，从行为学上完美区分敲击键盘召唤的“动态输入框”与双击唤出的“Windows UI输入框”。
4. **TSF 现代双轨与长效守护引擎 (v0.4.3 升级)**：基于微软原生 COM 标准（`msctf.idl` 真实规范 GUID）直接调度 TSF 线程与全局隔间转换模式，配合 200ms 静止态守护心跳，彻底攻克绘图区空白零操作无法恢复纯英文的顽疾，实现 0 按键模拟、0 闪烁、不干扰外部程序。


### 多重保险懒加载机制

引入懒加载策略：调整 IExtensionApplication.Initialize 中的初始化时机。监听 DocumentCreated / DocumentActivated 事件，待图纸就绪后再进行加载。完善超时保护机制，减少导致 CAD 启动卡死的可能。优化资源调用与挂载：订阅 AppDomain.AssemblyResolve 事件，保障高版本 CAD 中 WPF 资源的正常寻路。智能适配 MFC 消息循环（老版本）与 WPF/XAML 架构（新版本）。提供 2007~2027 各个 CAD 版本的差异化调用入口。

## ❓ 常见问题 (FAQ)

**Q1：为什么有些命令不自动切中文？**  
A：请排查以下几点：

1. 确认输入的是命令全称，而非快捷键。
2. 确认该命令已添加到配置面板的白名单中。
3. 部分插件的命令若通过非标准方式（如劫持菜单）触发，可能无法被底层的命令事件捕获。
4. 双击编辑文字等场景，请确认已升级至 v0.4.0 及以上版本。


**Q2：可以删除 TEXT、MTEXT等系统内置命令吗？**  
A：建议保留。这些是AutoCAD文字录入的基础命令，删除后将不再自动切换输入法。如遇误删，可通过配置面板的「恢复默认」功能进行重置。

**Q3：同时打开多张图纸会互相干扰输入法状态吗？**  
A：不会。自v0.3.1版本起已支持多文档状态隔离，每张图纸维护独立的输入法状态，切换文档窗口时会自动调整，互不干扰。

**Q4：安装/卸载时一直提示CAD在运行，强制关闭也没用？**  
A：这通常是因为 AutoCAD 占用了管理员权限，或者存在 accoreconsole.exe 残留进程。v0.4.1 安装包已优化进程清理机制：若确认已手动关闭可见的 CAD 窗口，在弹窗中选择“是（强行继续）”即可。
