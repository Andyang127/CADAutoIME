产品概述

🔹 产品定位

智能中英输入法自动切换 (CAD Auto IME) 是一款面向 AutoCAD 绘图环境的输入法协同工具。旨在解决画图过程中频繁手动切换中英文状态的繁琐操作。在 v0.4.3 版本中，通过重构状态机判定流程并完善 TSF 与 IMM32 接口同步，进一步提升日常绘图快捷键与文字编辑时的稳定性。

v0.4.3 版主要改进与特性

本次版本重点重构了命令生命周期判定流程，并完善了 TSF 与 IMM32 的接口调用：

TSF 与 IMM32 双轨状态控制架构示意

1. 延迟安全初始化

采用文档就绪监听与延迟加载逻辑，等待 AutoCAD 图纸数据库与工作窗口完全加载完成后再激活键盘与命令监听，避免在图纸尚未完全就绪时提前接入导致的异常。

2. 跨版本界面与依赖适配

针对 AutoCAD 2007 至 2027 不同世代所采用的运行环境（.NET Framework 2.0~4.8 以及 .NET 8.0/10.0），配置了程序集解析回调，保证配置面板能稳定加载并呈现。

3. 命令与文本编辑状态精准区分

结合 AutoCAD 的 CommandWillStart、CommandEnded 事件与系统变量 CMDNAMES，辅助底层消息时序判断，准确区分绘图命令输入与文本在位编辑，降低误切概率。

4. 可视化白名单与命令管理

配置面板直观呈现内置文本编辑命令与自定义扩展命令，工程师可根据绘图习惯自由添加需要激活中文的命令全称，或删除无需切换的指令。

5. 常见文字与标注命令支持

支持单行文字 (TEXT)、多行文字 (MTEXT)、表格编辑 (TABLEDIT)、引线标注 (LEADER) 以及双击修改文字等常用场景，进入文字输入阶段自动切中文，退出后即刻恢复英文。

常见问题解答

Q1：我可以把面板下方的 TEXT、MTEXT 等系统内置指令删掉吗？

A：建议保留。它们是 AutoCAD 常见的文字与标注录入指令。若从白名单中删除，执行对应命令时将不再自动切换输入法。如果误删，可随时点击面板下方的【恢复默认】按钮重新加载内置命令列表。

Q2：程序会影响 AutoCAD 运行速度、引起掉帧卡顿吗？

A：日常绘图基本无感。插件仅在按键触发、命令生命周期变化或焦点切换等关键节点进行轻量级状态检测。在绘图视口移动光标、漫游平移或缩放视图时不执行复杂逻辑，避免占用过多的 CPU 和系统资源。

Q3：同时打开多张图纸会互相影响吗？

A：各图纸文档独立维护输入法状态上下文。在图纸 A 编辑文字切为中文后，切换至图纸 B 绘图时会自动恢复为当前图纸的英文状态，互不干扰。

Q4：为什么安装/卸载时提示 CAD 正在运行？

A：如果系统后台仍有残留的 AutoCAD 进程或控制台服务（如 accoreconsole.exe），安装向导会检测到文件占用。请确认已保存图纸并关闭所有 CAD 窗口；若确已关闭，可在向导提示中选择继续执行安装或卸载。

Q5：为什么有时敲击快捷键时，拼音框和 CAD 动态输入框会叠在一起？

A：该现象通常是由于快捷命令与文字编辑状态判定发生重叠。v0.4.3 版本重新梳理了优先级判定树，在进入绘图画布与执行常规快捷键时优先保证英文状态，减少了叠框冲突。

卸载流程

本程序提供极其纯净的卸载体验，不留任何系统垃圾。

  1. 打开 Windows 「开始菜单」，找到 「CAD Auto Ime」 程序组。
  2. 点击 「卸载 智能中英输入法自动切换」 选项。
  3. 注意：为确保彻底清除注册表占用，卸载时若 CAD 正在运行，程序会弹出友好提示建议您保存图纸并协助自动关闭 CAD 进程。遇权限锁定时可选择强行跳过。

  • ⚡【Win32 TSF 原生规范与 GUID 架构级校准】：依照微软 Windows SDK (msctf.idl) 标准全面校准 TSF 原生 COM 接口与隔间 GUID 定义（精准纠正 IID_ITfCompartmentMgr、IID_ITfCompartment 与 GUID_COMPARTMENT_KEYBOARD_OPENCLOSE 等历史定义偏差），打通 Windows 10/11 现代输入法（微软拼音、搜狗、微信输入法等）底层双轨 COM 无损直连。
